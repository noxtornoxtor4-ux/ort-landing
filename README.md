# NOVA — лендинг записи на урок ОРТ

Одностраничный сайт учебного центра «НОВА» (Каракол). Ученик выбирает формат обучения и предметы,
указывает, когда ему удобно принять звонок, оставляет свой телефон и телефон родителя — и одним
нажатием отправляет готовую заявку администратору в WhatsApp.

Стек: Vite 8 + React 19 + TypeScript + SCSS-модули. Пакетный менеджер — **bun**.

## Запуск

```bash
bun install
bun run dev
```

Vite выведет два адреса:

- **Local** — `http://localhost:5173`, открывать на этом же компьютере;
- **Network** — `http://<ip-компьютера>:5173`, открывать с телефона в той же Wi-Fi сети.

Сетевой адрес нужен, чтобы проверить подстановку текста в мобильном WhatsApp: `localhost` с телефона
не откроется. Если Windows покажет запрос брандмауэра при первом запуске — разрешить для частных сетей.

Прочие команды:

| Команда           | Что делает                          |
| ----------------- | ----------------------------------- |
| `bun run build`   | Типизация (`tsc -b`) + прод-сборка  |
| `bun run preview` | Локальный просмотр прод-сборки      |
| `bun run lint`    | oxlint                              |

## Настройка

Весь изменяемый контент лежит в [`src/config/site.ts`](src/config/site.ts):

- `WHATSAPP_PHONE` — номер администратора только цифрами, с кодом страны, без `+` и пробелов.
  Сейчас `996776161109`.
- `CENTER` — название центра, полное название для подвала, город и номер в шапке.
- `FORMATS` — карточки «Офлайн в Караколе» / «Онлайн».
- `SUBJECTS` — предметы. Поле `formats` определяет, в каком формате предмет показывается:
  блоки по математике, кыргызскому и русскому языку идут в обоих форматах, химия и биология —
  только онлайн.
  При смене формата отметки сохраняются, отпадают лишь недоступные предметы.
- `CALL_SLOTS` — интервалы, в которые колл-центру удобно звонить.
- `BOOKING_HORIZON_DAYS` — на сколько дней вперёд открыт календарь (сейчас 14).
- `GRADES` — варианты в поле «Класс». `label` видно в списке, `phrase` уходит в текст заявки.

Логотип лежит в [`src/assets`](src/assets): `nova-logo.png` — исходник, `nova-wordmark.png` — знак
для шапки, обрезанный от подписи на кыргызском (в мелком размере она нечитаема).
Иконки собраны из знака в `public/`: `favicon.png` — круг с прозрачными углами для вкладки,
`apple-touch-icon.png` (180×180) — для домашнего экрана iOS, `icon-192.png` и `icon-512.png` —
для Android и `site.webmanifest`. На мобильных иконках знак стоит на красном квадрате: iOS заливает
прозрачность чёрным, а Android обрезает углы.

## Как формируется заявка

[`src/lib/whatsapp.ts`](src/lib/whatsapp.ts) собирает текст сообщения и ссылку
`https://api.whatsapp.com/send?phone=<номер>&text=<текст>`. Этот эндпоинт выбран вместо короткого
`wa.me`: десктопное приложение WhatsApp по нему стабильнее подставляет текст, а не открывает пустой чат.

CTA — обычная ссылка `<a href>`, а не `window.open`: программный вызов попапа блокируют Safari на iOS
и встроенные браузеры Instagram и TikTok, откуда идёт основной трафик.

Текст, который клиент увидит уже введённым в поле сообщения:

```
Здравствуйте! Меня зовут Айпери, я ученик 9 класса.
Хочу записаться на урок по ОРТ в NOVA.

📌 Детали заявки:
• Формат: Онлайн
• Предметы: Блок математика на русском, Химия
• Удобно позвонить: 23 сентября (среда), 12:00–15:00
• Телефон ученика: +996 700 11 22 33
• Телефон родителя: +996 555 99 88 77

Подскажите, пожалуйста, расписание и стоимость.
```

Этот же текст показывается на странице живым превью в виде WhatsApp-пузыря и обновляется на каждое
изменение формы.

> Надёжнее всего подстановка проверяется с телефона: откройте сетевой адрес из `bun run dev`,
> заполните форму и нажмите кнопку.

Телефоны нормализуются и валидируются в [`src/lib/phone.ts`](src/lib/phone.ts) (9 цифр, код `+996`,
маска `555 12 34 56`).

## Ссылка для Instagram

Превью ссылки задано в [`index.html`](index.html) тегами `og:*`: при отправке в WhatsApp, Instagram
или Telegram подтягиваются название, описание и логотип из `public/og-logo.png`.

`og:url` и `og:image` содержат абсолютный адрес — **при смене домена их нужно обновить**, иначе
превью перестанет показывать картинку.

```
  styles/         глобальные стили и токены
```
