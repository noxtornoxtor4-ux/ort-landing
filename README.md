# Лендинг «Подготовка к ОРТ» с записью в WhatsApp

Одностраничный конверсионный сайт для образовательного центра: ученик выбирает предметы ОРТ
и удобное время, вводит контакты и одним кликом отправляет готовую заявку администратору в WhatsApp.

Стек: Vite 8 + React 19 + TypeScript + SCSS-модули. Пакетный менеджер — **bun**.

## Запуск

```bash
bun install
bun run dev
```

Vite выведет два адреса:

- **Local** — `http://localhost:5173`, открывать на этом же компьютере;
- **Network** — `http://<ip-компьютера>:5173`, открывать с телефона в той же Wi-Fi сети.

Сетевой адрес нужен, чтобы проверить подстановку текста в мобильном WhatsApp: `localhost` с телефона
не откроется. Если Windows покажет запрос брандмауэра при первом запуске — разрешить для частных сетей.

Прочие команды:

| Команда           | Что делает                          |
| ----------------- | ----------------------------------- |
| `bun run build`   | Типизация (`tsc -b`) + прод-сборка  |
| `bun run preview` | Локальный просмотр прод-сборки      |
| `bun run lint`    | oxlint                              |

## Настройка перед публикацией

Всё, что меняется под конкретный центр, лежит в [`src/config/site.ts`](src/config/site.ts):

- `WHATSAPP_PHONE` — номер администратора только цифрами, с кодом страны, без `+` и пробелов.
  Сейчас указан `996706161109` (+996 706 161 109).
- `CONTACTS.phoneLabel` — номер в шапке сайта.
- `TIME_SLOTS` — варианты в поле «Удобное время». Значение уходит в заявку как есть, поэтому
  «Любое время» — обычный пункт списка. Подогнать под реальное расписание центра.
- `BOOKING_HORIZON_DAYS` — на сколько дней вперёд открыт календарь (сейчас 60).
- `SUBJECTS` — предметы. `required: true` делает пункт всегда выбранным и недоступным для снятия
  (так ведёт себя Основной тест).
- `GRADES` — варианты в поле «Класс». `label` — то, что видно в списке, `phrase` — как класс
  звучит в тексте заявки («ученик 11 класса», «выпускник школы»).

## Как формируется заявка

[`src/lib/whatsapp.ts`](src/lib/whatsapp.ts) собирает текст сообщения и ссылку
`https://api.whatsapp.com/send?phone=<номер>&text=<текст>`. Этот эндпоинт выбран вместо короткого
`wa.me`: десктопное приложение WhatsApp по нему стабильнее подставляет текст, а не открывает пустой чат.

CTA — обычная ссылка `<a href>`, а не `window.open`: программный вызов попапа блокируют Safari на iOS
и встроенные браузеры Instagram и TikTok, откуда идёт основной трафик.

Текст, который клиент увидит уже введённым в поле сообщения:

```
Здравствуйте! Меня зовут Эльдос, я ученик 11 класса.
Хочу записаться на пробный урок по ОРТ.

📌 Детали заявки:
• Предметы: Основной тест, Физика
• Удобный день: 14 сентября (понедельник)
• Удобное время: 16:00
• Телефон для связи: +996 555 12 34 56

Подскажите, пожалуйста, расписание и стоимость.
```

Этот же текст показывается на странице живым превью в виде WhatsApp-пузыря и обновляется на каждое
изменение формы.

> Надёжнее всего подстановка проверяется с телефона: откройте сетевой адрес из `bun run dev`,
> заполните форму и нажмите кнопку.

Телефон нормализуется и валидируется в [`src/lib/phone.ts`](src/lib/phone.ts) (9 цифр, код `+996`,
маска `555 12 34 56`).
